# molmodeling

抽象化した有機分子の骨格を3Dで組み立てるエディタ（骨格モデラー）。キラル分子の説明用。

- 形（原子・球・四面体・立方体など）を結合して分子を組む
- 色・質感・大きさ・結合長・結合次数を変更
- キラル中心・軸性キラルの自動表示、鏡像の並置
- 結合のまわりのねじれアニメーション（軸不斉のエナンチオマー間の変換）
- 自動回転（1回転の秒数・向き、画面の縦軸・任意の結合・結合に垂直な軸を回転軸に設定、角度指定の回転）
- 録画（MP4/WebM）、1回転ぴったりの動画も作成可能
- 背景が透明な1回転ループの透過GIF（スライド用）
- PNG書き出し、JSON保存/読込

`index.html` 1ファイルで動作します（three.js r128 をCDNから読み込み）。
